# Two-minute confounded-cohort demonstration

1. Run the confounded simulator and analysis from the README. Point out that the command succeeds: scientific refusal is a valid completed result.
2. Open **Decision Overview**. The recommendation is **No correction** because condition and processing batch cannot be estimated independently.
3. Open **Study-Design Audit**. Show the empty condition-by-batch cells, pairwise identifiability status, rank, and limiting pair.
4. Explain why choosing the method with the strongest apparent batch reduction would also risk removing protected biology.
5. Open **Root-Cause Evidence**. The first, highest-severity card prioritizes redesign and proposes balanced bridge samples or randomized reprocessing.
6. Close on **Reproducibility and Downloads**: the refusal, inputs, configuration, checksums, and exact supporting tables are retained.
