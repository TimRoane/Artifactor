## 0.5.0 — 2026-08-07

- Added `artifactor start`, a guided Analyze / Demo / Open home screen for new users.
- Added matrix orientation and sample-ID inspection, metadata-role suggestions with required review, self-contained project generation, and a preflight design verdict.
- Added first-class single-matrix studies alongside multi-modal configurations.
- Added selected corrected-data CSV exports, explicit refusal manifests, report download links, and `artifactor outputs` discovery.
- Added CLI `init` and `preflight`, recent-run reopening, assay templates, onboarding integration tests, and a getting-started guide.

## 0.4.0 — 2026-08-07

- Added checksum-frozen SEQC2 and CPTAC registries, resumable retrieval, immutable-source verification, deterministic adapters, preparation manifests, and transformation ledgers.
- Added typed preregistered evidence, non-evaluable outcomes, mechanically derived case-study conclusions, source-study comparisons, and deviation logs.
- Added external-validation HTML/Streamlit views, scientific run comparison, benchmark planning/measurement, and explicit estimated-versus-observed cost semantics.
- Corrected the draft CPTAC primary-proteome accession from phosphoproteome PDC000128 to official discovery-proteome PDC000127 before viewing results.

## 0.3.0 — 2026-08-07

- Added typed targeted-NGS coverage, allele-count, annotation, QC, control, and truth contracts with reference/panel/provenance validation.
- Added deterministic separable, confounded, FFPE-damage, and bridge-control scenarios.
- Added count-aware coverage attribution and guarded exploratory representation selection plus sampling-aware VAF, context, bias, read-support, control, and replicate diagnostics.
- Added NGS HTML, Streamlit, CLI, Nextflow stages, machine-readable evidence, scientific regression gates, and reproducibility telemetry without altering genomic observations.

## 0.2.0 — 2026-08-06
